# martifarran.me

Portfoli personal de Martí Farran Colell. Pàgina estàtica (`index.html`), sense build, preparada per a GitHub Pages.

## Revisió amb comentaris

`revisio/index.html` mostra la pàgina original dins d'un iframe i permet deixar-hi comentaris (💬 Comentar) i exportar-los en Markdown (🗒️ Comentaris). No modifica `index.html`. Els comentaris es desen al `localStorage` de cada navegador.
